# 关于解析

本目录只收录**真题题干**。客观题解析与主观题参考答案**未随仓库分发**
（那部分逐字来自商业机构的解析书）。

想补全解析：把你自己的解析文本放到 `source/真题库/解析/`（按 `YYYY年311教育学解析.md` 命名），
然后在 `app/` 下运行：

```bash
python extract_explain.py            # 客观题解析 → questions.extra.explain
python extract_subjective_answer.py  # 主观题参考答案 → questions.extra.answer_text
```

两个脚本都是规则抽取、不调用 AI、不花钱；跑完页面上交卷后就能看到解析。
