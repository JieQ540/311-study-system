# 311备考系统 · 使用说明

更新：2026-10-21。启动与依赖安装见[README](../README.md)。

1. 双击根目录 `启动系统.bat`，保留服务窗口；浏览器进入本机8765页面。
2. 想少量练主观题，用“主观题专项”；想按复习内容组题，用“日常练习”，先核对考点再组卷；整套计时练习用“模拟考试”。
3. 先独立作答，再查看参考或请求AI批改。文字与手写照片均可用于普通练习，照片先核对识别稿。
4. 核对小问实得分、原文证据和优先修改建议。成绩优先采用通过服务端对账的AI详细批改分，无需勾选采分点；采分点确认单独统计。
5. 点保存并核对结果。日志可回看原题、原答及批改；继续练习另建记录，不覆盖原场次。
6. 学习复盘正文与历史报告中的“第几题”按该场题单映射，点击可定位对应原题；未答题也保留位置。
7. 从具体题目开始订正，另存新作答；需要时安排普通间隔复测。默认1、3、7天，可调整或暂停。到期先锁定独立原答，再批改与保存。

AI总结可选，已有逐题记录无需再调用模型即可回看。不合理的复盘判断可排除，也可保存自己的总结修正版，重新生成AI报告不会覆盖修正。

没有可用AI分账时可按采分点自评。尚未评定、分值待核、对账失败和有效零分是不同情况，不据缺失分数推断答错或进步。

配置在 `config.json` 与 `config.local.json`，个人记录在 `data/kaoyan.db`。不要提交密钥、个人数据库、私有来源索引或无权公开的资料。公开仓库的覆盖与训练批次界面需另行导入有权使用的资料包。
