## 三、三个 AI 环节怎么设计

### ① 学习记录解析

**输入**（你的原话）：
> 「背诵外国教育史第四章 近代国家教育体制及其教育思想；第五章部分：夸美纽斯、卢梭、裴斯泰洛齐的教育思想」

**处理**：
- 把 **441 个考点的名称**（不是全文，只名字）放进 prompt
- AI 输出：匹配的考点 ID + 置信度
- **优化**：两阶段（先匹配「板块/章」，再在该章内选考点），可把 token 从 ~6000 降到 ~1500

**输出**：
```json
{"points": [{"id": 307, "name": "3. 裴斯泰洛齐的教育思想", "conf": 0.95}, ...]}
```

**要你确认**：如果 AI 定位错了怎么办？我建议 **界面上把识别的考点列出来让你勾选/增删**，再开始出题。—— 由你决定是否要这一步（多一次确认，但防跑偏）。

### ② 出题

**规则**：
1. **优先抽真题**：查库里挂在这些考点上的题
2. **不足则生成**：调 AI 按「考点 + 311 结构特征 + 真题风格」生成新题
3. 生成的新题**标记来源**（`AI生成`），便于日后区分

**要你确认**：每天出多少题？我建议默认 **10 道客观 + 2 道主观**（约 15 分钟做完），可调。

### ③ 批卷

**system prompt** = 已写好的 `docs/311主观题批改提示词.md`（含逐句标分、优化版、标准采分点）

**输入**：
- 题目 + 采分点/参考答案
- **你的手写照片**（flash 支持图像理解，可直接识别）

**输出**：按提示词格式的批改结果 + 结构化数据（命中采分点 / 缺失 / 错因）

**「言之有理」怎么实现**：
- 提示词中明确：**采分点外但论述合理的，给予额外加分标注**（不占标准采分点，单独记为「加分项」）
- 这部分**由 AI 判断，但标注清楚让你复核** —— 你可以推翻

## 七、我要提醒你的三个风险

1. **AI 定位考点会出错**：比如你说「第四章」，AI 可能对应到大纲的不同章节。所以第 3 条「考点确认」我强烈建议保留。
2. **AI 生成的新题质量未知**：可能出偏、可能重复考过的点。建议**标记来源 + 先观察几轮**，别一开始就当真题用。
3. **批卷的「言之有理」最不可靠**：AI 可能给不该给的分。所以**加分项单独标注、你可推翻**，不进采分点命中率统计（否则会污染薄弱点数据）。
