# 311 备考系统

面向考研311（教育学专业基础）的本地备考工具，使用Python、FastAPI和SQLite。浏览器访问本机页面，练习记录保存在自己的电脑；AI定位、出题、批改和总结使用使用者自行配置的模型服务。

更新：2026-10-21。同步专项、复盘订正、普通间隔复测与模型设置等功能；修复复盘正文显示内部作答代码的问题。

## 功能入口

| 入口 | 功能 |
| --- | --- |
| `/` 模拟考试 | 按实际题单与计时作答；试卷和草稿可恢复，提交后查看结果 |
| `/daily` 日常练习 | 定位并确认考点，选择题量及组卷方式；支持文本和手写照片批改 |
| `/practice` 主观题专项 | 按题型、科目与章节少量抽题，默认一次一道 |
| `/logs` 练习日志 | 按天查看每场题单、原答和批改；继续练习另存新记录 |
| `/reports` 学习复盘 | 逐题回看、整理问题、保存总结修正，并从具体原答开始订正 |
| `/retest` 普通复测 | 锁定原答后解锁批改；默认1、3、7天，可调整或暂停；同依据、同来源才计算差值 |
| `/settings` AI设置 | 查看供应商、模型和场景参数，明确保存后生效 |
| `/coverage`、`/pilot` | 资料覆盖和训练批次界面；需自行导入有权使用的资料包才有对应内容 |

公开仓库不附带个人作答、私有训练包、教辅原文或本机来源索引。普通题库和私有资料包的范围分别管理，界面存在不代表资料已经提供。

## 评分与复盘

普通练习成绩优先使用通过服务端对账的AI详细批改实得分，包括部分得分、加分、调整与封顶。无需先勾选采分点；采分点确认和掌握率统计另行保留。没有可用AI分账时仍可自评折合，分值待核时不给假满分或假零分。对账只能核验分数组成，不能保证学科判断正确。

复盘中的题号按本次题单显示，例如“第8题”。点击正文或历史报告中的题号，会打开对应场次的原题与原答。未答题保留位置，同题多次作答分别标明；旧报告在显示时转换，原文不被批量改写。没有可靠映射的引用标待核，不跳到别的练习。

## 快速开始

需要Python 3.10或更高版本。Windows双击根目录的 `启动系统.bat`：首次运行会检查并安装FastAPI、Uvicorn，服务启动后打开网页；保留服务窗口，用完关闭该窗口。

也可在仓库目录执行：

```bash
python -m pip install fastapi "uvicorn[standard]"
cd app
python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

打开 <http://127.0.0.1:8765>。首次运行把随包的 `data/kaoyan-seed.db` 复制为自己的 `data/kaoyan.db`，之后练习写入自己的库。随包种子用于初始化，不直接保存练习。

读取已有题目、原答和报告不需要调用模型。AI功能需自行配置：将 `config.example.json` 复制为 `config.json`，填写自己的模型服务配置，再通过设置页调整场景参数。设置覆盖保存于 `config.local.json`，基线配置保留。密钥和这两份配置均不应提交到Git。

操作步骤见[使用说明](docs/使用说明.md)，数值批改口径见[311主观题批改提示词](docs/311主观题批改提示词.md)。

## 数据与维护

- `data/kaoyan.db` 是个人库；运行中可能有SQLite事务日志，备份时需保证一致性。
- `data/kaoyan-seed.db` 是公开种子，无个人学习记录和私有训练包；本次软件更新沿用现有公开题库。
- `server.py` 负责接口与迁移，`review.py` 负责复盘证据及题号映射，`static/qa-answer.js` 复用答案与批改显示。
- `marks.py`、`pricing.py`、`providers.py` 分别处理分值形态、费用估算和模型目录。金额仅在有价目依据时估算。
- 参考缺失、配分待核或资料有争议时，以界面状态为准。AI生成题有来源标记，不冒充真题。
- 旧原答、成绩来源和批改保留，订正与续练另存。完成练习、生成报告或一次涨分不等于长期掌握。

## 验证

以下检查使用临时副本与模型桩，不把验收作答写入个人库，不调用付费模型：

```bash
cd app
python -X utf8 -B tests/test_review_references.py
python -X utf8 -B tests/test_ai_score_primary.py
node tests/test_qa_render.js
```

浏览器检查另需安装Playwright及Chromium：

```bash
python -m pip install playwright
python -m playwright install chromium
python -X utf8 -B verify_review_ui.py
```

浏览器用例自行建立副本和独立端口，检查桌面、手机、题号定位和真实保存；无需提前启动8765服务。

## 材料范围与限制

- 随包提供题目与答案，不提供商业机构解析长文、教辅PDF、扫描件或私有来源索引；参考缺失时需自行补入有权使用的材料。
- AI定位、识别与学科判断可能出错；应核对识别原文、依据和具体诊断。费用由自己的模型服务决定。
- 薄弱点统计依赖已确认的实际作答。未练不判薄弱，资料存在不代表掌握；样本不足时不编造个性化结论。
- 题目及答案著作权归各自权利人。自行加入的资料请遵循其版权要求，不再分发无权公开的内容。
- 本项目用于学习辅助与自测，不用于违反考试规则或学术诚信的用途。代码可自由使用与修改；权利人如对材料收录有异议，请提Issue联系处理。
